Bloqueantes — resolver antes de escalar
CRÍTICO Tipo de cambio hardcodeado ($1200)
Error de integridad financiera. Cualquier variación cambiaria produce métricas incorrectas, decisiones erróneas y pérdida inmediata de confianza del usuario. En Argentina esto es especialmente grave dado la volatilidad del tipo de cambio.
✦ Centralizar FX en microservicio dedicado · Versionar por fecha · Persistir conversiones históricas · Integrar fuente externa (ej. BCRA / Ambito API)
CRÍTICO Side-effect en carga del dashboard
triggerMonthlyGeneration() se dispara en el render inicial vía POST /finance/generate-month/ → GET /summary-full/. Esto introduce duplicación de datos, condiciones de carrera y degrada la performance de carga. Antipatrón peligroso en producción.
✦ Mover a cron job schedulado (ideal) · O endpoint idempotente con lock de ejecución y control por período ya generado
CRÍTICO Falta de auditabilidad en motor de IA
Los agentes FINA / ARKO / LUMEN generan insights y acciones concretas sin registrar qué datos usaron ni por qué llegaron a esa conclusión. El botón "Ejecutar $X" es peligroso sin confirmación doble, simulación previa y logging detallado.
✦ Implementar Audit Trail por cada decisión IA · Log de inputs + modelo + timestamp · Confirmación 2-step para ejecuciones · Modo simulación previo
Importantes — no bloquean, restan calidad
IMPORTANTE MarketTicker no responsivo
hidden lg:flex oculta el ticker en mobile. En Argentina la mayoría accede desde dispositivo móvil — este componente es invisible para el usuario promedio.
✦ Versión compacta: scroll horizontal tipo chip-row · O widget resumido colapsable · Priorizar mobile-first en toda la UI
IMPORTANTE TopMovers fuera del BFF + Settings duplicado
TopMovers realiza fetch independiente rompiendo el patrón BFF. Settings se consulta dos veces generando doble roundtrip. Inconsistencia arquitectural que acumula deuda técnica.
✦ Incorporar TopMovers al BFF · Centralizar Settings en singleton con cache · Auditar todos los fetches que salen del patrón
IMPORTANTE Speech API sin fallback + Anomalías truncadas
Speech API falla silenciosamente sin indicador de compatibilidad. Anomalías con .slice(0,3) cortan info sin opción de ver más — UX incompleta que oculta datos relevantes.
✦ Speech: fallback UI + indicador de compatibilidad del browser · Anomalías: "Ver más" con drill-down o modal detallado

Diagnóstico estratégico: FinApp ya tiene ADN de fintech inteligente. El desafío no es técnico en su core — es de confianza operativa. Resolver los 3 bloqueantes eleva el score promedio de 6.7 → 8.2 y habilita el camino a monetización real.
Plan de acción priorizado
Ahora
Servicio FX centralizado con histórico
Microservicio dedicado que consume fuentes oficiales (BCRA, Ambito, dolarito.ar). Versionado por fecha, persistencia de conversiones, endpoint único para todo el sistema. Elimina el mayor riesgo de integridad financiera.
Ahora
Fix generate-month → cron schedulado
Mover triggerMonthlyGeneration() a un job programado con idempotencia garantizada. Agregar control de "período ya generado" para evitar duplicaciones. Mejora performance de carga inicial significativamente.
Ahora
Fix: current_price duplicado en schema
Deuda técnica concreta que genera bugs silenciosos e inconsistencias ORM. Fix inmediato obligatorio antes de cualquier escala.
Próximo sprint
Motor de auditoría IA (Audit Trail)
Log inmutable por cada decisión de FINA/ARKO/LUMEN: inputs usados, modelo, versión, timestamp, confianza. Confirmación 2-step para ejecuciones financieras. Modo simulación previo. Clave para escalar y para compliance regulatorio.
Próximo sprint
Mobile-first UX completa
MarketTicker responsive (scroll horizontal). Anomalías con drill-down. Speech API con fallback UI e indicador de compatibilidad. Revisar toda la UI con viewport mobile como primera pantalla.
Próximo sprint
BFF unificación total + cache layer
TopMovers y Settings dentro del BFF. Cache con React Query en frontend + TTL por endpoint en backend. Elimina todos los fetches que rompen el patrón arquitectural.
Escala
Seguridad fintech: 2FA + logs auditables
Para PUT /transactions/{id} y ejecución de inversiones: confirmación doble, logs auditables con firma, 2FA opcional. Habilitador para mercado fintech real y eventuales requerimientos regulatorios (BCRA, CNV).
Escala
Motor de decisiones auditable para monetización
Dashboard de trazabilidad de insights IA para el usuario. Exportación de reportes auditables. Base para modelo SaaS B2B o white-label para advisors financieros.
Funciones nuevas propuestas
🧠
Modo Simulación Financiera ("What-if")
Panel interactivo donde el usuario puede simular escenarios antes de ejecutar: "¿Qué pasa si invierto $X en Y?" con proyección de impacto en balance, FCF y patrimonio. Los agentes IA corren en modo sandbox sin efectos reales.
Alto impacto · Media complejidad
📊
FX Dashboard con histórico y alertas
Visualización del tipo de cambio con histórico por período, comparativa entre fuentes (oficial, blue, MEP, CCL), y alertas configurables cuando el spread supere un umbral definido por el usuario.
Crítico para Argentina · Alta prioridad
🔔
Motor de Alertas Proactivas
Sistema de notificaciones inteligentes: alerta cuando un gasto supera el presupuesto, cuando una inversión cae X%, cuando se detecta una anomalía no vista, o cuando el flujo de caja proyectado entra en zona negativa.
Diferenciador · Media complejidad
📋
Reporte Financiero Exportable
Generación de informe PDF/Excel mensual con: P&L simplificado, evolución patrimonial, performance de inversiones, insights IA del período y recomendaciones. Clave para usuarios que rinden cuentas o asesores que usan la plataforma.
Monetizable · B2B ready
🤝
Modo Colaborativo / Advisor View
Rol de "asesor" que puede ver dashboards de clientes en modo lectura, agregar notas y recomendaciones sobre los insights IA, y compartir reportes. Habilita modelo B2B para advisors financieros sin acceso a ejecución.
Modelo de negocio · Alta complejidad
🔐
Audit Trail Visible para el Usuario
Sección "¿Por qué me sugirió esto?" donde el usuario puede ver el razonamiento completo del agente IA: datos usados, período analizado, nivel de confianza y fuentes. Genera confianza y diferencia de soluciones "caja negra".
Trust builder · Diferenciador clave
